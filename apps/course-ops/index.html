Course Ops

Product shell

Canvas course operations

Manage Canvas without fighting Canvas.

Course Ops is being built as the fast control layer for understanding existing Canvas shells, editing content, making bulk changes, and verifying what actually changed.

1

Inspect

Read the real Canvas shell and make course state understandable.

2

Select

Choose items across modules, object types, or courses.

3

Change

Make direct edits or define a safe bulk operation.

4

Review

Preview the exact change set before writing to Canvas.

5

Apply

Execute supported operations with explicit progress and failure handling.

6

Verify

Read Canvas back before reporting success.

This PR establishes the boundary only.

No Canvas mutation, bulk-edit, inspection, or authentication capability is represented as implemented yet. Those capabilities belong in focused follow-up patches with acceptance tests.
