# CourseBuild RC6.2 — Visual Polish

This patch responds to browser testing feedback about contrast and the visual relationship between the hero and left navigation.

## Changes

- Darkens muted copy, labels, inactive navigation, placeholders, and metadata for easier reading.
- Retains lavender as a brand accent but increases its contrast and limits it to emphasis rather than body text.
- Strengthens form-field boundaries and disabled-control legibility.
- Gives the hero a deliberate bottom separation so the rounded navigation panel no longer visually collides with the square hero edge.
- Keeps mobile spacing compact while carrying the contrast improvements through.

## Manual browser checks

1. Read hero body copy, section descriptions, labels, status chips, and inactive navigation at normal zoom.
2. Verify My Courses, Course setup, Blueprint, Content review, Canvas readiness, Adapt, and Settings all use readable text contrast.
3. Verify the desktop left navigation has clear visual separation from the hero.
4. Verify mobile does not gain unnecessary hero/nav spacing.
5. Recheck disabled controls: they should look disabled but remain legible.
